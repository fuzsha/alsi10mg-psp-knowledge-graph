# Competency Questions

1. Besides process parameters, what changes PV process features?

2. What is the reason for a higher standard deviation in any data? Was it because of one data point or one sample?

3. Can the change in observed data be tracked to any process parameter?

4. Why is there a difference between the average and root mean square values for surface roughness?

5. Which data are calculated from processing parameters, which are just observed data, and which are calculated from observed data?

6. What is the source of each data point, and what is the chain of data? (Where is each data point coming from, and what testing method was used to get it?)

7. Which data has been measured using multiple methods?

8. Do two different methods give similar results?

9. For mechanical property data, for a range of results, which parameter or structural property do they come from?

10. How much data is used to get into the master table?

11. If two samples have the same data for one process feature but differ in another, which constant or input parameter was changed?

12. Which samples had the same processing input but ended up in a different structural regime?

13. Why do we need process features when input parameters are already there? Do they do the same job?

14. When measuring multiple data points to get an average, how much disagreement was there? Were they close in value, or how much disagreement was there?

15. Does the pore count matter as much as pore volume?

16. Is the biggest pore a better predictor for failure than average pore size?

17. Were all the observation/measurement settings (such as X-ray CT) kept the same?

18. If any sample data looks wrong, is it possible to tell if the problem is with the sample or the measurement?

19. Do small hatch spacing and large hatch spacing specimens have similar mechanical properties?

20. How does one structural property change another structural property, and can this be found in the data?

21. Which sample had the most raw data, and is there any relation to its process parameters?

22. For finding Young's modulus, how much fitting is needed on the stress-strain curve?

23. Where did the curve stop being linear (Yield point), and was it consistent for all samples?
