# Link Names

Links are the lowercase words in the bracketed lists of the competency questions. Each one connects two key notions, and it is read in the direction of the arrow.

| Link | From → To | Meaning |
|---|---|---|
| hasValue | Sample → Reported Value | the sample has this value |
| hasLabel | Reported Value → Label | the value is this kind of number |
| memberOf | Sample → Group | the sample belongs to this group |
| hasProcessParameter | Sample → Process Parameter | the sample was printed with this setting |
| builtFrom | Reported Value → Raw Data | the value was made from these raw readings |
| calculatedBy | Reported Value or Label → Calculation | the value is worked out by this calculation |
| hasInput | Calculation → Label, Raw Data or Process Parameter | the calculation uses this as input |
| hasSource | Reported Value or Raw Data → Source | it comes from this file or paper section |
| measuredWith | Reported Value or Label → Test Method | it was measured with this method |
| hasMeasuredProperty | Sample → Measured Property | this property was measured on the sample |
| hasClass | Sample → Porosity Class | the sample is dense or porous |
| testedWith | Sample → Test Method | the sample was tested with this method |
| hasSetting | Test Method → Test Setting | the method was run with this setting |
